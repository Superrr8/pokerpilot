# Poker IQ v1

Poker IQ — локальный, производный показатель качества решений. Он не является
денежным результатом, GTO-рейтингом, ELO или обещанием будущего выигрыша.
Единственный источник данных — записи с `decisionQuality.isRated === true` из
существующей `progress.history`.

Decision Quality оценивает одно решение по шкале 0–100 и может меняться резко.
Poker IQ описывает долгосрочную устойчивость решений по шкале 1000–3000.
XP и Level отражают активность пользователя и не входят в формулу Poker IQ.
Будущий competitive ELO должен быть отдельной матчевой системой и в v1 не
реализован.

## Контракт

- диапазон: 1000–3000;
- модель: `poker-iq-v1.1`;
- схема кэша: 1;
- нейтральная точка: 1500;
- 0 решений: `score: null`, `sampleStatus: NONE`, ранг «Без ранга»;
- 1–9 решений: `PROVISIONAL`;
- 10–29 решений: `FORMING`;
- 30+ решений: `ESTABLISHED`.

Poker IQ не записывается в Profile как второй источник истины. Он
детерминированно пересчитывается из Decision Quality history; в
`pokerpilot_poker_iq_cache` хранится только восстанавливаемый кэш с fingerprint
источника и версией модели.

## Формула

1. Учитываются только конечные оценки Decision Quality от 0 до 100.
2. Дубликаты с одинаковым `decisionId` учитываются один раз.
3. Базовый DQ взвешивается:
   - последние 20 решений: 1.20;
   - решения 21–50: 1.10;
   - более старые: 1.00;
   - confidence: high 1.00, medium 0.92, low 0.80;
   - marginal: дополнительный множитель 0.90.
4. DQ переводится в IQ кусочно-линейной кривой:

| DQ | IQ до shrinkage |
|---:|---:|
| 0 | 1000 |
| 50 | 1100 |
| 60 | 1250 |
| 70 | 1450 |
| 80 | 1650 |
| 85 | 1800 |
| 90 | 2000 |
| 95 | 2250 |
| 100 | 2850 |

5. Небольшие ограниченные модификаторы учитывают стабильность,
   достоверность confidence и покрытие улиц.
6. Для established-выборки единичные выбросы ограничиваются медианой ±40 DQ,
   а стабильность измеряется медианным абсолютным отклонением.
7. Итог притягивается к 1500 псевдовыборкой весом 60:

```text
IQ = (observedIQ × N + 1500 × 60) / (N + 60)
```

Это защищает новый профиль от резких скачков и не позволяет одному решению
создать высокий ранг.

## Срезы и тренд

Engine возвращает независимые срезы `preflop`, `flop`, `turn`, `river`,
`postflop`, а также группировку по режимам. Отсутствующий срез равен `null`, а
не нулю. Тренд сравнивает две соседние выборки до 20 решений и возвращает
`UP`, `DOWN`, `STABLE` или `INSUFFICIENT_DATA`.

В конце Live Session история получает компактный immutable snapshot Poker IQ
до и после сессии. Денежный результат хранится и показывается отдельно и не
участвует в расчёте.

## Ограничения v1

- показатель зависит от качества и покрытия рекомендаций Trainer;
- малая выборка явно помечена как предварительная;
- нет серверной синхронизации, публичных рейтингов и лидерборда;
- нет ELO или сравнения с другими игроками;
- нет глобального percentile или показателя «Top X%»;
- нет гарантии соответствия solver/GTO;
- кэш можно безопасно удалить: он будет восстановлен из history;
- изменение версии Decision Quality или Poker IQ инвалидирует кэш.
