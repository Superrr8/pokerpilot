# AGENTS.md — постоянные инструкции Codex для PokerPilot

## Источник требований

Перед любой работой прочитай:

1. `POKERPILOT_MASTER_SPEC.md`
2. `CODEX_ROADMAP.md`
3. `TESTING.md`

## Текущая база

- локальная рабочая версия: `PokerPilot v1.5.2-tested`;
- быстрый baseline: `28 passed, 0 failed, 0 TODO, 0 skipped`;
- основной код пока находится в `index.html`;
- прогресс хранится в `localStorage`.

## Обязательные правила

1. Не публикуй проект и не отправляй изменения на GitHub без отдельного явного задания.
2. Не меняй больше файлов и функций, чем необходимо для текущего этапа.
3. Не выполняй большой рефакторинг одновременно с изменением покерной логики.
4. Перед исправлением бага сначала добавь тест, который его воспроизводит.
5. После изменения запускай полный быстрый набор тестов.
6. Не копируй PokerCore в тесты; тестируй реальный код проекта.
7. Не изменяй ключи `localStorage` без миграции.
8. Не показывай правильный ответ до решения пользователя.
9. Не допускай повторяющиеся карты.
10. Не используй Monte Carlo, если точный перебор достаточно быстрый.
11. Monte Carlo в тестах обязан иметь фиксированный seed или статистически обоснованный допуск.
12. Рекомендации тренера должны обозначать допущения и уровень уверенности.
13. Не выдавай эвристическую рекомендацию за абсолютный GTO-ответ.
14. Не устанавливай внешние зависимости без явной необходимости и объяснения.
15. Не удаляй существующие функции без подтверждённой замены и регрессионных тестов.

## Защищённое поведение

Нельзя случайно потерять:

- режимы «Экзамен / Тренировка / Разбор»;
- Hand Lab;
- 18 постфлоп-сценариев;
- префлоп-тест;
- 6-max / 9-max Live;
- pot odds, required equity и EV;
- strong / conditional / dirty outs;
- exact next-card / by-river probabilities;
- equity и win/tie/lose;
- адаптивный Coach;
- историю и прогресс;
- отображение десяток как `10`;
- отсутствие подсветки ответа до решения.

## Порядок работы

Для каждого этапа:

1. Кратко опиши план.
2. Перечисли файлы, которые собираешься менять.
3. Внеси минимальные изменения.
4. Запусти тесты.
5. Покажи:
   - passed;
   - failed;
   - TODO;
   - skipped;
   - список изменённых файлов;
   - известные ограничения.
6. Не переходи к следующему этапу автоматически.

Следующий рекомендуемый этап:
